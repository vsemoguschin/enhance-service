# 2026-08-28-adaptive-codex-face-references

## Задача

Реализовать согласованный production-пайплайн Codex: не уменьшать близкие к выходному
размеру оригиналы, большие входы перед генерацией адаптивно уменьшать, а лица передавать
отдельным supporting reference вместе с подсказками теней и фактуры. Для явно тёмного
одиночного лица разрешить дополнительный осветлённый face-reference. Не менять внешний API.

## Аудит

- C1 уже получает оригинал как multipart-файл; URL разрешает и скачивает вызывающий сервис.
  Менять HTTP-контракт и повторно скачивать изображение здесь не требуется.
- `app/codex_provider.py` сейчас всегда записывает полноразмерный authoritative original и
  две supporting-копии (тени/фактура). Face-reference отсутствует.
- `imagegen` принимает не более пяти `referenced_image_paths`. Поэтому безопасная схема —
  основной кадр + две общие подсказки + оригинальный непрерывный crop лиц; пятый вход только
  для осветлённого crop одного явно тёмного лица.
- Лабораторная матрица на 1024/2048/2560 показала потерю фактуры на 1024 и разумный компромисс
  на 2048. Большие оригиналы уменьшаются только когда длинная сторона больше 2560; меньшие не
  увеличиваются и не уменьшаются.
- Crop должен строиться из полноразмерного EXIF-нормализованного оригинала до уменьшения.
  Для группы нужен один непрерывный фрагмент, чтобы сохранить пространственное соответствие
  людей; отдельная сетка лиц повышает риск перепутывания.
- Детектор лиц может ошибаться или ничего не найти. При отсутствии уверенных детекций пайплайн
  обязан продолжать текущим трёхреференсным маршрутом, не падать и не отправлять случайный crop.
- Затрагиваются `app/config.py`, `app/codex_provider.py`, `app/prompts.py`, `.env.example`,
  health-диагностика, тесты и документация провайдера.

## План

1. Добавить конфигурацию и чистые функции адаптивного resize и построения face-context crop.
2. Расширить формирование prompt/вызов Codex до четырёх или пяти явно размеченных входов.
3. Сохранить безопасный fallback на существующие три reference при отсутствии лиц.
4. Покрыть границы resize, crop, порядок/лимит references и fallback unit-тестами.
5. Обновить эксплуатационные параметры и прогнать тесты на реальных лабораторных оригиналах.
