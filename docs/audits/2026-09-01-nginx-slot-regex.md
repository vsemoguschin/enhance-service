# 2026-09-01-nginx-slot-regex

## Задача

Исправить production nginx template, обнаруженный при первом blue/green deploy.

## Аудит

`nginx -t` отклонил regex location: некавыченный квантификатор `{32}` был разобран как
отдельная директива `32}$`. Reload не выполнялся, рабочий сервис не затронут. Production-копия
была точечно заключена в кавычки и после этого прошла `nginx -t`.

## План

Заключить оба slot-aware regex в двойные кавычки, проверить diff и повторно подтвердить шаблон
на production через `nginx -t`.

## Результат

Заполняется после реализации.
